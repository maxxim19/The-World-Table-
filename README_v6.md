# The World Table — v6

This version replaces the photographic country cards with compact printed-menu cards modeled on the supplied reference.

## Versioned source files
- `index_v6.html`
- `styles_v6.css`
- `script_v6.js`

## GitHub Pages
GitHub Pages requires a root `index.html`, so this folder also contains `index.html` as an exact deploy copy of `index_v6.html`. The actual CSS and JavaScript remain versioned, which also prevents browsers from reusing the old v5 stylesheet from cache.

Upload all four web files to the repository root. GitHub Pages will open `index.html`, which loads `styles_v6.css` and `script_v6.js`.
